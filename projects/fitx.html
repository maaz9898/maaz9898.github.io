FitX: Real-Time Exercise Form Analysis

A mobile app that counts repetitions and flags form errors using pose estimation.

  • Pose estimation
  • MediaPipe
  • Mobile
Role

Stack
Python, MediaPipe
Features
Rep counter, form error detection
Platform
Mobile

Overview

The app tracks body joints through the phone camera, counts each repetition and notifies the user when their form deviates.

How It Works

Joint angles are computed from the detected keypoints on every frame. A repetition counts only when the knee angle passes the depth threshold and returns to standing. Try both modes.
